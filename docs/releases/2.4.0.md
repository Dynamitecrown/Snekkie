# Snekkie 2.4.0

Snekkie 2.4.0 adds configurable terminal animations, automatic paging for all `show` commands, and hover switching between the top menus. Animations and automatic paging are both **off by default**. Saved sessions, themes and existing preferences carry over.

## Typing and console output animations

Enable **Settings → Preferences → Animations → Animations** to animate typing and incoming console output. Choose styles independently for nine kinds of effect:

| Effect | Available styles |
|---|---|
| Cursor movement | Off, Glide, Spring, Smear, Ghost |
| Cursor blink | Classic, Fade, Pulse, Glow |
| Typed characters | Off, Pop, Bounce, Flash, Fade |
| Keystroke burst | Off, Sparks, Confetti, Embers, Bubbles, Stars, Ripple |
| Screen shake | Off, Gentle, Strong |
| New output text | Off, Fade, Rise, Drop, Zoom, Decode, Heat |
| Output reveal | Instant, Typewriter, Word by word, Line by line |
| Scrolling | Off, Smooth, Float, Spring |
| New output lines | Off, Glow, Flash, Marker, Underline, Shimmer |

- A speed slider adjusts effects from **0.5× to 2×**. Cursor blinking keeps its usual rhythm.
- A live terminal preview demonstrates typing, commands and output using the selected styles and colors. It updates before you save, and stops animating when its page is hidden.
- The master switch disables the style controls while retaining your choices. **OK** saves the choices; **Cancel** discards edits.
- Turning animations on affects fresh activity rather than replaying text already on screen. Full-screen applications such as `vim`, `nano` and `htop` skip output effects while retaining typing effects.
- Reveal effects catch up within half a second at normal speed, or one second at the slowest speed. Typing immediately reveals any output still waiting to appear.

## Automatic paging for all show commands

Enable **Terminal → Auto-page show commands** or **Settings → Preferences → General → Automatically page through show commands** to advance long listings without repeatedly pressing Space.

- Applies to all submitted `show` commands, including `show run`, `show running-config`, `show interfaces`, `show version`, `sh`/`sho` abbreviations and `do show` commands.
- Recognises Cisco IOS `--More--` / `---More---` and ASA `<--- More --->` prompts, including colored prompts and prompts split across incoming reads.
- Sends one Space per page across SSH, serial, telnet and raw TCP. Duplicate redraws of the same prompt do not send extra Spaces.
- Works in background tabs and while the window is minimised. Pager responses do not create local echoes or typing effects, and incoming session logs retain the original bytes.
- Both controls change the same saved setting and apply immediately to open and new tabs. Enabling it applies to subsequent show commands; disabling it cancels any pending automatic response.
- Press **q** or **Ctrl+C** to stop. Other manual input, disconnection, reconnection and entering a full-screen application also cancel automatic paging. Manually advancing a page supersedes its pending automatic response.
- Command recognition handles Backspace, line editing, recalled history, completion and commands wrapped over several terminal rows, even while viewing scrollback. Pastes that queue several commands are left for manual paging.
- Unrelated commands, ordinary text containing a More marker, and confirmation questions are not automatically answered.

## Menus and Preferences

- Click **Session**, **Edit**, **Terminal**, **View**, **Settings** or **Help**, then hover over another top menu to open it without another click. Switching works in both directions, directly between distant menus, and while a submenu is open.
- Hovering an idle menu bar does not open menus. Escape, clicking outside, clicking an open menu and choosing an item retain their normal dismissal behaviour.
- Preferences now has separate **General** and **Animations** pages, with consistent width and stable button placement when switching pages.
- Preferences pages scroll in shorter windows so the page tabs, **OK** and **Cancel** stay accessible.

## Animation correctness and responsiveness

- Corrected movement detection for repeated console logs, sparse output and progress blocks redrawn in place. Forward output keeps moving forward; scrolling back moves in the correct direction.
- Scroll regions keep fixed status lines in place. Animated text, cursor positions, line marks and particles remain aligned with the live screen and scrollback, including wide characters.
- Delayed command echoes retain typing effects after Enter, including when the echo and its reply arrive together. The reply retains its separate output effects. Keys that are not echoed, such as password input, do not leave stale expectations behind.
- Animation state resets appropriately when reconnecting, clearing or resetting the terminal, resizing, changing animation settings, or returning to a tab that was hidden.
- Large output bursts batch text rendering and limit expensive individual glyph effects. Particle counts are bounded, and the terminal stops requesting continuous redraws once effects have settled.
- The preview sends output in bursts so Typewriter, Word by word and Line by line can be distinguished from Instant.

## Settings, documentation and release tooling

- Animation styles, speed and automatic paging are persisted in `settings.json`. Missing or malformed new values fall back to defaults; unknown styles fall back to their default, and animation speed is kept within the supported range.
- Updated the README with all new features, their controls and defaults, a link to these notes, and current installer and release examples.
- Bumped the application version to **2.4.0** in Cargo metadata and the lockfile. The About dialog, update checks and Windows packaging derive their version from that metadata.
- The release workflow publishes these complete version-specific notes with the Windows installer, portable executable and Linux tarball. Releases without a notes file retain the generated-notes fallback.
- Excluded generated Python `.egg-info` metadata from version control.
