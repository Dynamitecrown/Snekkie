# Snekkie 2.10.0

Snekkie 2.10.0 adds SSH jump hosts and tunnels, OpenSSH config import, a batch of everyday terminal improvements, three new full app appearances and more animations. Existing profiles and preferences carry over.

## Jump hosts

- **Connect through a bastion:** pick another saved SSH session as a session's **Jump host** (ProxyJump). Jump hosts can have their own jump hosts, up to 5 in a chain. Loops and missing sessions are refused with a clear message.
- **Each hop logs in on its own:** each hop uses its own key, agent or password, and checks its own host key, with the jump host named in the prompt. Errors name the hop that failed, such as a jump host that can't reach the next one or a connection lost at a jump host.
- The file explorer, transfers, tunnels and agent tools all work through jump hosts.
- See [Jump hosts](https://github.com/Dynamitecrown/Snekkie/blob/v2.10.0/docs/jump-hosts.md).

## Tunnels

- **Local, remote and dynamic (SOCKS5) port forwards** per saved SSH session, under **Tunnels** in the session form. They start when the tab connects, stop when it closes, and come back on **Reconnect**.
- **Safe by default:** tunnels listen on 127.0.0.1 only. **Allow other computers to connect** opens one to the network and shows a warning while it is ticked.
- **See what they do:** the status bar shows how many tunnels are up, and the **Tunnels** window lists each rule with its state and open connections. A rule that fails, such as a port already in use, is named in a notice and the others keep working.
- Offline mode still applies to connections a remote tunnel makes on this computer.
- See [Tunnels](https://github.com/Dynamitecrown/Snekkie/blob/v2.10.0/docs/tunnels.md).

## Import from OpenSSH

- **Settings → Import → OpenSSH config** reads the Host blocks in `~/.ssh/config`, or another file, with the same preview as the PuTTY import. Nothing in the file is run.
- Host names, users, ports and key file paths are imported. `ProxyJump` to another imported host becomes its jump host, and simple `LocalForward`, `RemoteForward` and `DynamicForward` lines become tunnels. Tunnels imported this way always listen on 127.0.0.1.
- PuTTY imports now bring in simple port forwardings as tunnels too.

## Terminal and sessions

- **MFA and one-time codes:** keyboard-interactive prompts open a dialog. The saved password only answers a lone password prompt.
- **Bracketed paste:** when bash, zsh or vim asks for it, a paste goes as one marked block, so it isn't run line by line.
- **Clickable links:** Ctrl+click (Cmd+click on macOS) a web address to open it, or an IP address to fill in the New session form with it. Nothing connects until you do. Offline mode keeps links from opening.
- **Bell and remote titles:** a bell from a tab you aren't looking at marks that tab. You can also show the title the remote host sets on the tab, and let remote programs set your clipboard with OSC 52. Both are off by default.
- **Device prompt:** a prompt such as `SW1#` names serial and unsaved tabs. The status bar shows whether the device is in user, privileged or config mode.
- **Reconnect when back:** right-click a dropped tab and Snekkie checks the port until the host answers, then reconnects. It keeps checking for up to 30 minutes.
- **Check port:** right-click a saved session to try one TCP connection and see open, refused or timed out.
- **Reopen tabs from last time** (off by default) puts your saved-session tabs, file explorers and split view back on the next start, disconnected, until you choose **Reconnect**.
- **Serial line endings:** choose what Enter sends (CR, LF or CR+LF), and optionally show a received LF as CR+LF.
- **Highlight rules:** up to 50 of your own patterns, each plain text or a regular expression, with a color and optional bold. They apply in every session.
- **Button bar:** turn on **View → Button bar** for one-click snippet buttons above the terminal. Each opens the usual review page before anything is sent.
- **Agents can reconnect a dropped session.** You still answer any password or host key question.

## Themes and animations

- **Space Super:** stars and planets behind the whole app. With animations on, they react to new terminal text and to your pointer, and Ctrl+Shift+drag moves a planet.
- **Neon Super** and **Sonar Super** are two more full app appearances.
- **Six new palettes:** Aurora, Rose Dusk, Graphite, Ember, Sandstone Light and Harbor Light.
- **Ten new animation styles:**
  - Keystroke bursts: Comet, Fireflies and Orbit.
  - Typed characters: Jelly and Neon.
  - Cursor blink: Heartbeat.
  - New text: Flicker and Glitch.
  - New lines: Wipe and Beacon.
- Animations remain off by default.

## Fixes

- SSH agent login on Windows now falls back to the OpenSSH agent when Pageant isn't running.

## Compatibility and verification

Saved profiles, themes, logging settings, snippets and paste controls remain compatible. If you save sessions in an older copy of Snekkie, it drops jump hosts and tunnels, though the sessions themselves are kept.

Jump hosts and tunnels were tested against a real OpenSSH server, including:
- Chains of up to five hops.
- A hop that drops.
- 100 MB of data through tunnels, checked byte for byte.
- 50 connections at once.
- SFTP and SCP through a jump host.
- Reconnecting with tunnels up.

Regression coverage adds in-process SSH servers for MFA, jump chains and forwarding. The other new features were checked through the app's interface in automated tests. The new appearances and animations were checked in rendered screenshots only. They still need a look on the systems where they are used.
