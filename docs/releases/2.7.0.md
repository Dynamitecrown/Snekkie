# Snekkie 2.7.0

Snekkie 2.7.0 reorganizes Preferences, makes saved-session actions clearer, adds quieter animation options and three palettes, and expands installation choices for Linux and macOS. Existing profiles and preferences carry over.

## Preferences and appearance

- Preferences now has **Appearance**, **Terminal**, **Input & paste**, **Network**, **Highlighting** and **Animations** sections. Tabs wrap in narrow windows, each section remembers its scroll position, and **Save changes** and **Cancel** stay visible at the bottom.
- Theme edits, saved-theme changes and settings remain drafts until **Save changes**. Cancel or Escape discards edits across every section.
- Appearance and Terminal previews use the draft's actual font family and size, with a prompt, interface table, error, cursor and selection. Settings explain whether they affect existing sessions or future connections.
- **Frost Light**, **Copper Night** and **Forest Night** bring the built-in palette count to 21. Both Solarized foregrounds have stronger text contrast. Existing saved custom themes retain their colors.
- Offline mode shows the number of network sessions that will close before you save. Cancel preserves the connections; serial sessions remain connected.
- See the [Preferences guide](https://github.com/Dynamitecrown/Snekkie/blob/v2.7.0/docs/preferences.md).

## Animations and reduced motion

- **Steady** keeps the cursor visible without blinking, a halo or idle blink redraws.
- **Focus** gently fades new text into place; **Bookends** and **Outline** briefly mark new output without moving its text.
- **Reduce motion** selects a steady cursor, immediate typing and scrolling, instant reveal and a short opacity-only output fade, with no particles or shake. It remains a draft until saved.
- Typing and Output controls sit side by side when space allows and stack in compact windows. Animations remain off by default, and saved individual choices survive disabling the master switch.

## Saved sessions and connection controls

- **Connect selected** and double-click connect using the saved profile without replacing an unfinished connection form. **Edit connection** loads the profile for editing without connecting.
- The **New session** form collapses to leave more room for saved sessions. Editing a profile reopens it. Saved-session actions remain reachable in compact layouts.
- **Show sessions / Hide sessions**, beside the tabs, and **Ctrl+B** (**Cmd+B** on macOS) toggle the sidebar. Its visibility is saved; hiding it preserves the form and filters.
- Connection tabs use distinct dots, rings and crosses for connection states, with destination tooltips and accessible status text.
- The **Key file** field appears only for SSH key authentication. Network **Keepalive** moves to Advanced. **Device** is now labeled **Highlighting**, and **None** becomes **Off**.
- See the [session sidebar guide](https://github.com/Dynamitecrown/Snekkie/blob/v2.7.0/docs/session-sidebar.md).

## Installation and platform support

- Windows keeps the stable **Snekkie-Setup.exe** master installer, with versioned full installers for offline installation and rollback. Installed copies can update through Snekkie; portable copies link to the release downloads.
- Linux downloads now include **`.deb`**, **`.rpm`**, **Flatpak**, **AppImage** and the portable tarball. A unified install script selects a suitable package and verifies release checksums before installing.
- macOS gains a universal **`.app`** in a **DMG**, native Command shortcuts and clipboard integration, platform default fonts, and virtual serial-port support without forcing a baud rate. The preview is ad hoc signed, without Developer ID signing or notarization; the [platform guide](https://github.com/Dynamitecrown/Snekkie/blob/v2.7.0/docs/linux-and-macos.md) explains first launch.
- Windows downloads remain unsigned. The [signing policy](https://github.com/Dynamitecrown/Snekkie/blob/v2.7.0/docs/code-signing.md) describes the optional free signing path.
- PuTTY SSH imports default to password authentication unless an explicit supported OpenSSH key is configured.
- See [Installing on Linux and macOS](https://github.com/Dynamitecrown/Snekkie/blob/v2.7.0/docs/linux-and-macos.md) and the [master installer guide](https://github.com/Dynamitecrown/Snekkie/blob/v2.7.0/docs/master-installer.md).

## Compatibility and verification

Saved profiles, custom themes, logging settings, snippets and paste controls remain compatible. Regression coverage includes Preferences save/cancel and preview behavior, compact layouts, saved-session draft preservation, connection targeting, palette contrast, animation settling and platform installation lifecycles. Visual checks use temporary settings and fictional local terminal output.

Native clipboard/file dialogs, physical serial hardware and real vendor-device workflows still need checks on the systems where they are used.
