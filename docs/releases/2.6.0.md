# Snekkie 2.6.0

Snekkie 2.6.0 adds saved command snippets, multiline paste review and pacing, configurable right-click behavior, and local input/output logging with password controls. Existing profiles and preferences carry over.

## Saved command snippets

- Open **Edit → Command snippets…** or press **Ctrl+Shift+S** to create, group, filter and reuse named command templates.
- Temporary `{{name}}` variables expand into a command preview with the destination shown. Variable values are not saved or automatically filled with credentials.
- **Insert into draft** opens an editable local draft. Editing, Enter and Cancel send no commands. **Send commands** submits reviewed commands with manual-paste line endings and a final CR.
- Destinations stay bound to the original session and connection. Tab changes cannot redirect a snippet; reconnecting or closing that destination invalidates it.
- Selected-template JSON import/export preserves existing templates and uses collision-safe names. Templates live separately in `snippets.json`; damaged or unsupported stores are preserved.
- See the [command snippets guide](../command-snippets.md).

## Paste review, pacing and right-click behavior

- Multiline clipboard paste opens an editable **Review paste** dialog by default, with its destination and line count shown. Cancel and Escape send nothing; single-line paste remains immediate.
- Queued pastes use a saved **100 ms** delay between lines by default. Choose **0–5,000 ms** in the preview or Preferences. Snippets use the same controller and saved delay.
- **Stop paste** discards remaining lines. Disconnect, reconnect, closing the destination or quitting also cancels pending commands. Delayed frames never send a catch-up burst.
- CRLF, LF and CR become CR on the wire; empty lines and an unsubmitted final line are retained. Typing and mouse input on the destination are blocked while its queue runs, and dialogs pause the queue.
- **Preferences → General → Right-click pastes (PuTTY style)** defaults on. Turning it off opens the context menu on plain right-click. Ctrl+right-click opens the menu in either mode. Copy-on-select remains available.
- Keyboard, menu and mouse pastes share the review flow. Plain Ctrl+V retains its terminal control-key behavior; use Ctrl+Shift+V for clipboard paste.
- See the [paste behavior guide](../paste-behavior.md).

## Local session logging

- Configure logging per saved profile under **Advanced → Logging options**. Readable text logs record sent input (**TX**) and received output (**RX**) with UTC timestamps. Raw output uses a companion `.input.log` file for sent input.
- **Automatic log filename** provides a local path using sanitized host, date and session substitutions. Files append; new profiles default to 10 MiB and daily rotation, with archives preserved.
- **Log passwords defaults off**. Common sensitive prompts, their echoed input and recognized credential-bearing lines are redacted. **Private input** suppresses both directions for unusual prompts and overrides password logging.
- Explicit password logging can record terminal passwords, SSH authentication passwords and key passphrases in local plain text. Profile import/export turns the option off so sharing cannot enable it elsewhere.
- Automatic recognition cannot identify every secret or vendor prompt. Use Private input before unrecognized sensitive workflows. Logs remain separate from on-screen text, clipboard selections and terminal exports.
- Background logging keeps file writes out of the UI. Failures warn once and stop logging while the connection continues. Normal application exit drains pending records; the status bar reports logging status and opens the resolved log folder.
- Older profiles retain their raw format and prior rotation defaults. See the [session logging guide](../session-logging.md).

## Terminal search fixes

- Literal and selected-text searches match displayed tab gaps, including regex-mode selection prefill.
- Search preserves actual Unicode whitespace, ignores grid padding and concealed text, and handles reversed or off-grid ranges.
- Current results refresh after reflow or replaced text. Added regressions for resize, trimmed history and alternate-screen changes.

## Validation and packaging status

- Local Windows validation: **334 tests passed, one existing live-release test ignored**. Formatting, locked all-target Clippy with warnings denied, the optimized build and diff checks passed.
- Real egui/wgpu renders were reviewed in four themes at 1000×640 and 520×320 using temporary stores and fictional local TCP output.
- Native clipboard/file dialogs, physical serial hardware and Linux runtime were not exercised locally. The release workflow checks Windows and Linux, then builds the Windows installer, portable executable and Linux tarball.
- Cargo metadata, About and Windows executable resources use **2.6.0**. Installed Windows copies can update from 2.5.0 through the startup offer or **Help → Check for updates…** when online updates are enabled. The updater downloads `Snekkie-Setup-2.6.0.exe` and checks its published SHA-256 before installation. Portable Windows and Linux copies retain their release-page download flow.
